时间复杂度

很好，这个是很多做Data Structures和Algorithms题目时常用的 “3秒判断循环时间复杂度口诀”。掌握后很多选择题基本可以秒做。⚡

一、第一步：先看 n 在哪里出现

核心原则：

情况 时间复杂度

没有 n O(1)
一层 n 循环 O(n)
两层 n 循环 O(n²)
三层 n 循环 O(n³)

例如：

for(i=0;i<n;i++)

就是：

O(n)

如果是：

for(i=0;i<n;i++)
for(j=0;j<n;j++)

就是：

O(n²)

二、第二步：看变量是“常数”还是“规模”

考试最容易错的是这个。

情况1：变量是常数

x = 90;
y = 100;

while(y > 0)
y–;

循环次数：

100 次

所以：

O(1)

因为 100 是常数，不是规模 n。

情况2：变量来自输入

如果是：

y = n;

while(y > 0)
y–;

循环次数：

n 次

所以：

O(n)

三、第三步：看变量增长方式

① 每次 +1 或 -1

i++
i–

复杂度：

O(n)

例子：

for(i=0;i<n;i++)

② 每次乘或除

i = i * 2
i = i / 2

复杂度：

O(log n)

例子：

for(i=1;i<n;i=i*2)

循环次数：

1 → 2 → 4 → 8 → … → n

所以：

O(log n)

四、第四步：嵌套循环看乘法

例子：

for(i=0;i<n;i++)
for(j=0;j<n;j++)

复杂度：

n × n = O(n²)

如果是：

for(i=1;i<n;i=i*2)
for(j=0;j<n;j++)

复杂度：

log n × n = O(n log n)

五、一个考试最爱出的陷阱题

for(i=0;i<n;i++)
for(j=0;j<i;j++)

很多人以为：

O(n²)

其实严格是：

1 + 2 + 3 + … + n

结果：

n(n+1)/2

所以仍然是：

O(n²)

（常数忽略）

六、再看你刚才那题为什么是 O(1)

因为：

x = 90
y = 100

都是：

常数

循环次数：

≈1000

仍然是：

常数

所以：

O(1)

七、考试最常见复杂度总结（一定要背）

复杂度 常见代码

O(1) 常数次操作
O(log n) i*=2
O(n) 单循环
O(n log n) log循环嵌套n
O(n²) 双循环
O(n³) 三循环
