# 多态

## 1.认识多态

### 什么是多态？

+ 多态是在<font color=red>继承/实现</font>情况下的一种现象，表现为：对象多态、行为多态。

#### **多态的具体代码体现：**

```java
People p1= new Student();
r1.run();

People p2=new Teacher();
p2.run();
```

### 多态的前提：

+ 有<font color=red>继承/实现</font>关系；
+ 存在父类引用子类对象；
+ <font color=red>存在方法重写</font>。//导致每个对象的行为不一样

### 多态的一个注意事项

+ 多态是对象、行为的多态
+ Java中的属性(成员变量)不谈多态。
  - 对于方法：编译看左边，运行看右边；
  - 对于成员变量：编译看左边，运行也看左边。

---

## 2.多态的好处

### 使用多态的好处

+ 在多态形式下，右边对象是解耦合(模块化)的，更便于扩展和维护

+ 定义方法时，使用父亲类型的形参，可以接收一切子类对象，扩展性更强、更便利。

```java  
public class Test {
    static void main(String[] args) {
        Animal a1=new Sheep();
        a1.run();
        go(a1);
        Animal a2=new Wolf();
        a2.run();
        go(a2);

    }
    public static void go(Animal a){
        System.out.println("开始。。。");
        a.run();
    }
}
```

### 多态下会产生的一个问题

+ 多态下不能使用子类的独有功能。

---

## 3.多态下的类型转换

### 转换形式：

+ 自动类型转换：父类 变量名 =new 子类();

```java
People p=new Teacher();
```

+ 强制类型转换：<font color=red>子类 变量名=(子类)父类变量</font>
  - 解决多态下调用子类独有功能。

```java
Teacher t=(Teacher)p;
```

### 强制转换的一个注意事项：

+ 存在继承/实现关系就可以在编译阶段进行强制类型转换，编译阶段不会报错。
+ 运行时，如果发现对象的真实类型与强转后的类型不同，就会类型转换异常(ClassCastException)的错误出来。

##### 强转前，Java建议：

+ 使用 **instanceof** 关键字，判断当前对象的真实类型，在进行强转。

```java
p instanceof Student
//对象 instanceif 类型
```
