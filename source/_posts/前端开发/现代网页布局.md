# 现代网页布局

## CSS布局

CSS布局是网页设计的核心技术之一，用于控制元素在页面中的排列方式

每种技术都有它们的用途，各有优缺点，相互辅助。

| 英文 | 中文 | 核心属性 | 说明 |
| :--- | :--- | :--- | :--- |
| normal | 正常布局 | 无 | 浏览器默认的标准流排版 |
| display | 模式转换布局 | `display` | 块级 / 行内 / 行内块 之间转换 |
| flexbox | 弹性布局 | `display: flex` | 一维布局（一行或一列） |
| position | 定位布局 | `position` | 脱离文档流、层叠、固定 |
| grid | 网格布局 | `display: grid` | 二维布局（行列同时控制） |
| column | 多列布局 | `column-count` | 文字内容自动分栏 |

**如何选择：**

+ 简单布局：优先使用 Flexbox（一维）或 Grid（二维）。
+ 复杂响应式布局：使用 Grid + 媒体查询。
+ 文本内容分栏：多列布局（column-count）
+ 兼容旧浏览器：浮动布局 或 Flexbox 的降级方案。
+ CSS Grid 逐渐成为主流，支持更复杂的布局场景。

## CSS正常布局流

正常布局流（normal flow）是指在不对页面进行任何布局控制时，浏览器默认的 HTML 布局方式。也称为标准流。
正常布局流是 CSS 布局的基石，页面大的布局基本就是利用区块元素上下罗列而成。

**区块元素(block)**

+ 独占一行，宽度默认撑满父容器。
+ 垂直方向排列，可设置宽高。
+ 示例：div、p、h1等。

**行内元素(inline)**

+ 水平方向依次排列，直到容器宽度不足则换行。
+ 宽度和高度由内容决定，无法直接设置。
+ 示例：span、img、strong 等

**文档流方向**

+ 默认从上到下、从左到右排列

## 模式转换

### display显示属性

正常流中的所有内容都有一个display的属性，用作元素的默认行为方式

在浏览器开发者工具的 Styles 面板中可以直观看到：`div` 的 `display` 值为 `block`，`a` 的 `display` 值为 `inline`。

但是开发的时候，我们需要一个块级盒子一行排列，或者行内元素需要设置大小，怎么办？——这就是 `display` 模式转换要解决的问题。

### display转换

**display属性**允许我们更改元素默认的显示方式。

| 属性值                  | 转换类型   | 说明 | 是否独占一行 | 能否设置宽高 | 默认宽度             |
| :---------------------- | :--------- | :--- | :----------: | :----------: | :------------------- |
| `display: block`        | 区块元素   | 常用 |      是      |      ☑       | 撑满父容器宽度       |
| `display: inline`       | 行内元素   | 罕见 |      否      |      ✕       | 由内容决定           |
| `display: inline-block` | 行内块元素 | 较少 |      否      |      ☑       | 由内容决定（可覆盖） |

表单元素默认 `inline-block`，其它元素想要转换可以：`display:inline-block;`

**使用场景：**

1. 让块级盒子一行显示。
2. 让行内盒子具备宽度高度。

**注意：**

1. 行内块元素中间会有空白缝隙。给父元素字号改为0可以去掉。
2. 实际开发适合于**对间距要求不高**的情况下可以转换。
3. 如果真的精细布局，请用 flex 或者 grid 更合适。

### 浮动

浮动(float)最早是做“文字环绕”效果的。例如：给图片添加float: left; 样式

浮动(float)可以让元素**脱离文档流**，向左或向右浮动，直到碰到父容器边缘或其他浮动元素

| 属性值 |      作用      |      示例       |
| :----: | :------------: | :-------------: |
|  left  |    左侧浮动    | `float: left;`  |
| right  |    右侧浮动    | `float: right;` |
|  none  | 默认值，不浮动 | `float: none;`  |

> **脱离文档流：**盒子会浮到其他文档流（标准流）之上，浮动的盒子不占位置，但会影响周围元素的布局。

**浮动带来的影响：**

1. 父盒子没有高度。（很多情况下不能给父元素指定高度）
2. 子元素浮动。
3. 影响其他盒子布局了。

### 清除浮动

**清除浮动**也可以理解为**闭合浮动**，简单来说，就是让浮动的元素尽量控制在父盒子内，不要影响其他盒子。

清除浮动主要有四种方式：

#### 1. 额外标签法

- **原理**：在浮动元素的最后面，新增一个块级标签。
- **做法**：给新增的标签添加属性 `clear: both;`。

#### 2. 单伪元素清除浮动

- **原理**：给父元素添加伪元素。

- **应用示例**：京东

- **代码实现**：

  ```css
  .clearfix:after {
      visibility: hidden;
      clear: both;
      display: block;
      content: ".";
      height: 0;
  }
  ```

#### 3. 双伪元素清除浮动

- **原理**：给父元素添加双伪元素（`:before` 和 `:after`）。

- **应用示例**：小米

- **代码实现**：

  ```css
  .clearfix:after,
  .clearfix:before {
      content: "";
      display: table;
  }
  
  .clearfix:after {
      clear: both;
  }
  ```

#### 4. overflow 清除浮动

- **原理**：给父元素添加 `overflow` 属性（通常值为 `hidden` 或 `auto`，触发BFC）。
- **做法**：父元素添加 `overflow`。

## flex布局

### 弹性盒子

Flexbox 是 CSS 弹性盒子布局模块（Flexible Box Layout Module）的缩写，可以快速实现元素的对齐、分布和空间分配。

**核心：**

1、父控子（亲父子）

- 父盒子控制子盒子如何排列布局
- 父盒子称为容器，子盒子称为项目

2、主轴和交叉轴（侧轴）

+ 主轴默认水平方向，交叉轴默认垂直方向，可以更改

> **记忆图：**容器内横向排列若干“项目”，贯穿容器的一条水平箭头线是“主轴”（main axis），与它垂直的另一条箭头线是“交叉轴”（cross axis）。

**容器设置 `display: flex` 后的表现：**

- 如果子元素有大小，则按照给定大小来显示。
- 如果子元素没有大小，则拉伸充满父容器。
- 若子元素总宽度超过容器宽度，默认会压缩子元素。

> 开发中大部分情况下，父容器设置 `display: flex`，子元素设定大小。

```css
.box {
  display: flex;
  width: 500px;
  height: 100px;
  border: 1px solid red;
}
.box .item {
  width: 100px;
  background-color: pink;
  border-radius: 10px;
}
```

**容器（父盒子）属性**：

| 属性            | 作用                                                         | 示例                                           |
| :-------------- | :----------------------------------------------------------- | :--------------------------------------------- |
| display         | 定义元素为 Flex 容器                                         | `.container { display: flex; }`                |
| flex-direction  | 定义主轴方向（项目排列方向）                                 | `.container { flex-direction: row; }`          |
| flex-wrap       | 控制是否换行                                                 | `.container { flex-wrap: wrap; }`              |
| justify-content | 定义主轴上的对齐方式（整体分布）                             | `.container { justify-content: center; }`      |
| align-items     | 定义交叉轴上的对齐方式（单行时整体对齐）                     | `.container { align-items: center; }`          |
| align-content   | 定义多行时交叉轴上的对齐方式（仅当 flex-wrap: wrap 且内容换行时生效） | `.container { align-content: space-between; }` |

#### justify-content（主轴对齐）

| 属性值        | 效果                                             |
| :------------ | :----------------------------------------------- |
| flex-start    | 左对齐（默认）                                   |
| flex-end      | 右对齐                                           |
| center        | 居中对齐                                         |
| space-between | 两端对齐：首个元素放起点，末尾元素放终点         |
| space-around  | 每个项目两侧分配相同的空间（两端留半个间隔）     |
| space-evenly  | 项目之间、首尾与边界的间隔完全相等               |

```css
.box {
  display: flex;
  /* 主轴的对齐方式 */
  justify-content: space-evenly;  /* 平均分配 */
  width: 500px;
  height: 100px;
  border: 1px solid red;
}
```

#### align-items（交叉轴对齐，单行）

| 属性值     | 作用描述                                       |
| :--------- | :--------------------------------------------- |
| flex-start | 项目在交叉轴起点对齐                           |
| flex-end   | 项目在交叉轴终点对齐                           |
| center     | 项目在交叉轴居中对齐                           |
| stretch    | 项目拉伸填充整个容器高度（**默认值**，需子项目未设置高度） |

> 典型应用：B 站顶部导航栏用 `align-items: center` 让图标与文字垂直居中。

#### flex-direction（主轴方向）

| 属性值         | 描述                                       | 示例效果              |
| :------------- | :----------------------------------------- | :-------------------- |
| row            | 默认值。子元素沿水平主轴（从左到右）排列   | A B C（横向排列）     |
| row-reverse    | 子元素沿水平主轴反向排列（从右到左）       | C B A（反向横向排列） |
| column         | 子元素沿垂直主轴（从上到下）排列           | A B C（纵向排列）     |
| column-reverse | 子元素沿垂直主轴反向排列（从下到上）       | C B A（反向纵向排列） |

```css
.sanlian li a {
  display: flex;
  flex-direction: column;  /* 改变主轴的方向 */
  justify-content: center; /* 主轴居中对齐 */
  align-items: center;     /* 交叉轴居中对齐 */
  height: 100%;
}
```

#### flex-wrap（是否换行）

| 属性值       | 排列效果                                       |
| :----------- | :--------------------------------------------- |
| nowrap       | 不换行（全部横向排列，可能被压缩）             |
| wrap         | 换行（第一行在上方，第二行在下方）             |
| wrap-reverse | 翻转（第一行在下方，第二行在上方，了解即可）   |

#### align-content（多行交叉轴对齐）

| 属性值        | 效果                           |
| :------------ | :----------------------------- |
| flex-start    | 上对齐                         |
| flex-end      | 下对齐                         |
| center        | 居中对齐                       |
| space-between | 首行贴顶、末行贴底，行间均分   |
| space-around  | 每行两侧分配相同的空间         |
| space-evenly  | 行与行、首末行与边界的间隔相等 |

> 注意：`align-content` 仅在 `flex-wrap: wrap` 且内容发生换行时才生效。开发中该属性使用较少，大部分子元素顺序排列即可。

**项目（子盒子）属性：**

| 属性        | 作用                                                      | 示例                            |
| :---------- | :-------------------------------------------------------- | :------------------------------ |
| order       | 定义项目的排列顺序（默认 0，数值越小越靠前）              | `.item { order: -1; }`          |
| flex-grow   | 定义项目的放大比例（默认 0，即不放大）                    | `.item { flex-grow: 1; }`       |
| flex-shrink | 定义项目的缩小比例（默认 1，空间不足时等比缩小）          | `.item { flex-shrink: 0; }`     |
| flex-basis  | 定义项目在主轴方向上的初始大小（默认 `auto`，优先级高于 width/height） | `.item { flex-basis: 200px; }`  |
| flex        | flex-grow、flex-shrink、flex-basis 的简写                 | `.item { flex: 1; }`            |
| align-self  | 覆盖容器的 align-items，单独定义某个项目的交叉轴对齐方式  | `.item { align-self: center; }` |

**flex 简写语法：**

> `flex: 1;` → `flex: 1 1 0%`，剩余空间占 1 份，并且可以伸缩盒子大小
>
> `flex: 2;` → `flex: 2 1 0%`，剩余空间占 2 份
>
> 数字表示剩余空间所占份数，通常写正整数，也可以写小数（如 `flex: 0.5` 占半份）。

```css
.box .item {
  /* flex 要写到小盒子身上，优先级比 width 和 height 高 */
  flex: 1;       /* 表示占 1 份 */
  width: 80px;   /* 会被 flex 覆盖 */
}
```

**`width` 与 `flex: 0 0 200px` 的区别（不换行时）：**

| 写法              | 效果                                                     |
| :---------------- | :------------------------------------------------------- |
| `width: 200px`    | 所有子盒子会占据父容器剩余空间，超出时出现压缩情况       |
| `flex: 0 0 200px` | 子盒子不拉伸、不收缩，每个子盒子宽度就是 200px（可溢出容器） |

### gap间距

gap 简写属性用于设置行与列之间的间隙（间距）

> **使用场景：**让子元素之间保留间隙
>
> **语法：**
>
> `gap: 20px;` 行和列之间保持 20 像素间隙。
>
> `gap: 20px 30px;` 行间距是 20 像素，列间距是 30 像素。

> **注意：gap 要写到父元素（容器身上）**

```css
.box {
  display: flex;
  gap: 10px;
  width: 80%;
  margin: 0 auto;
}
```

### 图片底部空白缝隙与 vertical-align

**基线（baseline）：**浏览器**行内元素**（行内块元素）排版中存在用于对齐的基线。

图片默认和文字基线对齐，因此图片下方会多出一段空白缝隙。

> **解决方案：**
>
> 1. 把图片转换为块级元素（`display: block;`）。
> 2. 设置图片对齐方式不是基线对齐即可。

```css
img {
  /* 方案二：改变垂直对齐方式 */
  vertical-align: middle;
}
```

| 属性值   | 效果           |
| :------- | :------------- |
| baseline | 默认，基线对齐 |
| top      | 顶部对齐       |
| middle   | 中部对齐       |
| bottom   | 底部对齐       |

> 让图片和文字垂直居中，用 `vertical-align: middle;` 即可。

### 弹性布局实战

**案例一：百度图片**

多列瀑布流思路：外层是一行 flex 容器，内部放若干列（`.item`），每列再纵向罗列图片。

```css
.col-flex {
  display: flex;
  gap: 16px;
  width: 1180px;
  margin: 20px auto;
}
.col-flex .item {
  flex: 1;             /* 每列等宽 */
}
.col-flex .item a {
  overflow: hidden;    /* 溢出隐藏 */
  display: block;
  width: 100%;
  border-radius: 18px;
  margin-bottom: 15px;
}
.col-flex .item a img {
  vertical-align: middle;
  width: 100%;
}
```

**案例二：淘宝 / 京东多行弹性布局写法**

```css
/* 淘宝写法：负 margin 抵消内边距，实现等间距 */
.box {
  display: flex;
  flex-wrap: wrap;
  margin-left: -8px;
  margin-right: -8px;
}
.box .item {
  flex: 0 0 16.666666%;  /* 一行 6 个 */
  padding: 0 8px;        /* 用 padding 撑出间隙 */
  margin-bottom: 16px;
}
```

```css
/* 京东写法：min-width / max-width 卡死每列宽度 */
.box .item {
  flex: 1;
  min-width: calc(16.6666667% - 16px);
  max-width: calc(16.6666667% - 16px);
  margin: 0 8px 16px;
}
```

**案例三：小兔鲜首页（综合实战）**

公共样式的拆分思路：

```
css
├── base.css     初始化 css 文件，去除默认样式，方便后期其他文件引用
├── common.css   公共 css 文件，存放头部、底部等复用结构
└── index.css    首页 css 文件
iconfont         字体图标
images           背景小图片，比如精灵图、logo 等
uploads          产品类图片，后期更换方便存放
favicon.ico      网页 favicon 图标
index.html       首页 html 文件
```

> **公共样式好处：**
>
> 1. 多次使用，节约代码。
> 2. 方便维护，统一修改。

```html
<!-- 网页图标 favicon 图标，一定放到根目录下 -->
<link rel="icon" href="./favicon.ico" type="image/x-icon">
```

**logo 做法：**

1. logo 用 `h1` 提高权重
2. 里面包含链接，可以点击跳转到首页。
3. 给链接设置背景图片，并且给链接添加 `title`。
4. 链接里面写网站名字，把文字隐藏。
   - 可以利用 `text-indent` 负值，然后 `overflow: hidden;`

```css
.header .logo a {
  display: block;
  width: 100%;
  height: 100%;
  background: url(../images/logo.png) no-repeat;
  text-indent: -999px;
  overflow: hidden;
}
```

**entry 结构拆分：**通栏容器 `entry` 内部由左右两部分组成——左侧 `category`（分类菜单），右侧 `banner`（轮播图）。

**单行文本溢出省略号（做成公共类）：**

```css
.ellipsis {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

```html
<h3 class="title ellipsis">男女情侣抗菌夜视休闲跑鞋</h3>
```

**实战总结：**

1. 设计稿很重要，可以提高我们开发效率。
2. 对布局理解更深刻了。先整体自上而下标准流布局。
3. 大部分盒子一行显示，主轴两端对齐，交叉轴居中对齐。
4. 如果遇到一行内左右分组的情况，注意嵌套盒子，然后再两端对齐。
5. 根据相关性进行盒子拆分。
6. 公共样式可以拆分单独 css，甚至单独的类。
7. 给盒子起个类名是个好习惯，能尽量减少样式冲突。

   ```html
   <li>
     <a href="#">
       <img src="./uploads/goods1.png" alt="">
       <h3 class="title">KN95级莫兰迪色防护口罩你值得拥有</h3>
       <p class="price"> <small>¥</small>79</p>
     </a>
   </li>
   ```

8. 写注释是个好习惯。

> 布局并不唯一，能实现就是好的。多练习、多模仿别人，会让自己的技术进步。

## grid布局

### 弹性布局 flex 与网格布局 grid 对比

| 对比项   | flex                                         | grid                                           |
| :------- | :------------------------------------------- | :--------------------------------------------- |
| 维度     | 一维布局，只能在单一方向（水平或垂直）上排列 | 二维布局，可以同时控制行和列的排列             |
| 适合场景 | 线性排列、单行布局、动态内容对齐             | 复杂页面框架、多列或响应式布局                 |

> 实际开发大部分是两者混用的：
>
> 1. **Flexbox**：适合快速实现一维布局、动态内容对齐。比如单行布局
> 2. **Grid**：适合构建复杂页面框架，提供更强大的二维控制能力。比如多列或者响应式等

**网格布局（CSS Grid Layout）**是一种**二维布局模型**，允许开发者通过定义行（rows）和列（columns）来精确控制网页元素的位置和尺寸，还可以实现响应式设计。

> 典型页面结构：顶部导航用 flex 单行布局，主体多行多列区域用 grid，其余部分走正常流。

### 网格基本概念

```html
<section>
  <div>盒子1</div>
  <div>盒子2</div>
  <div>盒子3</div>
  <div>盒子4</div>
</section>
```

| 概念    | 说明                                                         |
| :------ | :----------------------------------------------------------- |
| 容器    | 设置了 `display: grid` 的父盒子                              |
| 项目    | 容器内的直接子元素                                           |
| 行 / 列 | 由 `grid-template-rows` / `grid-template-columns` 划分       |
| 单元格  | 行与列交叉形成的最小格子                                     |
| 网格线  | 划分网格的线，编号从 1 开始                                  |

> 网格布局的核心：创建好网格并放入各类元素。

### 网格容器

容器（父盒子）设置 `display: grid;`（块级）或者 `display: inline-grid;`（行内）。

与弹性盒子不同的是，在定义网格后，网页并不会马上发生变化。因为 `display: grid` 的声明只创建了一个只有一列的网格。

### 网格轨道

网格轨道（Grid Tracks）决定了网格容器的基础布局结构，为子元素提供放置的位置。

> **绘制网格（网格轨道）：**
>
> `grid-template-columns` 定义网格中的列
>
> `grid-template-rows` 定义网格中的行
>
> **属性值：**
>
> - 有几个属性值代表创建几列/行
> - 长度单位，比如 `100px`

```css
.box {
  display: grid;
  /* 创建列轨道 */
  grid-template-columns: 100px 100px 100px;
  /* 创建行轨道 */
  grid-template-rows: 100px 100px 100px;
  width: 320px;
  height: 320px;
}
```

#### 轨道尺寸的写法

| 属性值   | 说明                                                         | 示例                                         | 应用场景                   |
| :------- | :----------------------------------------------------------- | :------------------------------------------- | :------------------------- |
| 固定长度 | 使用 px、em 等固定单位定义列宽                               | `grid-template-columns: 100px 200px;`        | 需要精确控制列宽的固定布局 |
| 百分比   | 按容器宽度百分比分配列宽                                     | `grid-template-columns: 30% 70%;`            | 响应式布局中按比例划分列   |
| fr 单位  | 分配轨道剩余空间的比例，`1fr` 表示一份，总和为容器剩余空间（fr 是 fraction 缩写，意思是分数） | `grid-template-columns: 1fr 2fr;`            | 需要自适应比例分配的布局   |
| auto     | 列宽由内容自动撑开                                           | `grid-template-columns: auto 100px;`         | 内容宽度不确定时的灵活布局 |
| repeat() | 简化重复的列定义                                             | `grid-template-columns: repeat(3, 1fr);`     | 多列等宽布局               |
| minmax() | 定义列宽的最小值和最大值                                     | `grid-template-columns: minmax(100px, 1fr);` | 响应式布局中限制列宽范围   |

### 轨道对齐方式

**justify-content** 控制列轨道（Column Tracks）在容器内水平分布。

**align-content** 控制行轨道（Row Tracks）在容器内垂直分布。

| 属性值        | 水平方向效果                             | 垂直方向效果                             |
| :------------ | :--------------------------------------- | :--------------------------------------- |
| start（默认） | 左对齐                                   | 顶部对齐                                 |
| end           | 右对齐                                   | 底部对齐                                 |
| center        | 水平居中对齐                             | 垂直居中对齐                             |
| space-around  | 两侧留出相等的空白，轨道周围空间均匀分布 | 上下留出相等的空白，轨道周围空间均匀分布 |
| space-between | 首尾轨道贴边                             | 上下轨道贴边                             |
| space-evenly  | 轨道间、首尾与边界的空白相等             | 轨道间、首尾与边界的空白相等             |

```css
.box {
  display: grid;
  grid-template-columns: 100px 100px 100px;
  grid-template-rows: 100px 100px 100px;
  justify-content: space-between; /* 列轨道两端对齐 */
  align-content: space-between;   /* 行轨道两端对齐 */
  width: 320px;
  height: 320px;
}
```

### 网格间距 gap

**gap** 简写属性用于设置行与列之间的间隙（网格间距）。

> **语法：**
>
> `gap: 20px;` 行和列之间保持 20 像素间隙。
>
> `gap: 20px 30px;` 行间距是 20 像素，列间距是 30 像素。
>
> **也可以分开写：**
>
> `column-gap: 30px;`
>
> `row-gap: 20px;`

```css
.box {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: 1fr 1fr 1fr;
  gap: 10px;
}
```

### repeat() 与 minmax()

> **语法：**`repeat(次数, 轨道尺寸)` 或 `repeat(自动填充, 轨道尺寸)`

**1. 指定次数：**

```css
/* 等效于 1fr 1fr 1fr */
grid-template-columns: repeat(3, 1fr);
```

**2. 自动填充（适用于响应式布局中“列数随容器宽度变化”的场景）：**

| 关键字      | 含义                                                             |
| :---------- | :--------------------------------------------------------------- |
| `auto-fill` | 尽可能多地创建列，容器空间远大于子元素大小时**留有空白空间**     |
| `auto-fit`  | 尽可能拉伸列填满容器（会合并空白，列宽不小于 `minmax` 的最小值） |

```css
/* 核心响应式写法 */
grid-template-columns: repeat(auto-fill, minmax(210px, 1fr));
```

> **注意：**`auto-fill` 和 `auto-fit` 的差别在容器空间远远大于所有子元素大小时才明显——`auto-fill` 保留空白列，`auto-fit` 把子元素拉伸占满父容器。

**minmax()：**`minmax(最小值, 最大值)`，例如 `minmax(200px, 1fr)`。

### 网格线

网格线会在使用网格布局时被创建。

> 线编号从 1 开始计算，3 列就会有 4 根线（列线 1、2、3、4；行线同理）。

**使用场景：**实现元素跨越多个网格单元格（如 B 站首页左侧大图 + 右侧视频网格）。

**实现语法 1 —— 开始线编号 / 结束线编号：**

```css
.grid-item {
  background-color: pink;
  grid-column: 1 / 3;  /* 从第 1 根线到第 3 根线，即跨 2 列 */
  grid-row: 1 / 3;     /* 从第 1 根线到第 3 根线，即跨 2 行 */
}
```

**实现语法 2 —— 开始线编号 / span 跨单元格数量：**

```css
.grid-item {
  grid-column: 1 / span 2;  /* 从 1 线开始，跨 2 个单元格 */
  grid-row: 1 / span 2;     /* 从 1 线开始，跨 2 个单元格 */
}
```

> **注意：**该属性要加到**项目（子元素）**身上。

```css
/* 仿 B 站布局：第一个项目占 2×2 */
.box {
  display: grid;
  grid-template-columns: repeat(5, 1fr);
  gap: 10px;
}
.box .item:first-child {
  grid-column: 1 / span 2;
  grid-row: 1 / span 2;
  height: auto;
}
```

> **练习推荐：**Grid Garden（https://cssgridgarden.com/）小游戏，用代码控制网格项跨列来给菜园浇水。

### 网格填充方式 grid-auto-flow

`grid-auto-flow` 决定网格容器中子元素排列填充方式。

> **语法：**
>
> 1. `grid-auto-flow: row;`（默认）子元素按先行后列顺序填充，优先填满一行后换行
> 2. `grid-auto-flow: column;` 子元素按先列后行顺序填充，优先填满一列后换列

**场景：**B 站、蔚来布局中有些子元素是按照列方式显示。

```
grid-auto-flow: row;          grid-auto-flow: column;
┌───┬───┬───┐                 ┌───┬───┬───┐
│ 1 │ 2 │ 3 │                 │ 1 │ 4 │ 7 │
├───┼───┼───┤                 ├───┼───┼───┤
│ 4 │ 5 │ 6 │                 │ 2 │ 5 │ 8 │
├───┼───┼───┤                 ├───┼───┼───┤
│ 7 │ 8 │ 9 │                 │ 3 │ 6 │ 9 │
└───┴───┴───┘                 └───┴───┴───┘
```

```css
.box {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 1fr 1fr;
  grid-auto-flow: column;  /* 修改网格填充方式 */
}
```

### object-fit / object-position

`object-fit` 是 CSS 中用于控制替换元素（如 `<img>`、`<video>`、`<iframe>` 等加载外部资源的元素）内容如何适应其容器尺寸的属性。

| 值      | 描述                                                                         |
| :------ | :--------------------------------------------------------------------------- |
| fill    | 默认值。拉伸内容以完全填充容器，不保持宽高比，可能导致内容变形（最常用但需谨慎） |
| contain | 保持内容固有宽高比，缩放至完全适应容器内部（内容全部可见），容器可能有空白   |
| cover   | 保持内容固有宽高比，缩放至覆盖容器（内容可能部分被裁剪），容器无空白         |

**object-position：**控制内容在容器内的对齐位置（如 `center` 居中、`top left` 左上角），常与 `object-fit` 搭配使用（例如 `cover` 时调整裁剪区域）。

```css
.box img {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center;
}
```

### 项目对齐方式

在 CSS Grid 布局中，`justify-items`、`align-items` 控制元素在网格单元格内的对齐方式。

> **语法：**
>
> 1. `justify-items`：水平对齐方式（行轴方向）
> 2. `align-items`：垂直对齐方式（列轴方向）
> 3. `place-items`：水平 + 垂直方式
>
> 为了提高可读性和兼容性，提倡使用前面两种方式。

> **注意：**给父容器添加。

| 属性值  | 水平方向效果                 | 垂直方向效果                 | 代码示例                                |
| :------ | :--------------------------- | :--------------------------- | :-------------------------------------- |
| start   | 对齐单元格起始边缘（左对齐） | 对齐单元格起始边缘（顶部对齐） | `.container { justify-items: start; }`  |
| end     | 对齐单元格结束边缘（右对齐） | 对齐单元格结束边缘（底部对齐） | `.container { justify-items: end; }`    |
| center  | 水平居中对齐                 | 垂直居中对齐                 | `.container { justify-items: center; }` |
| stretch | 拉伸填满单元格宽度（默认值） | 拉伸填满单元格高度（默认值） | `.container { justify-items: stretch; }` |

```css
.box {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(3, 1fr);
  /* 项目（子元素）对齐方式 */
  justify-items: center; /* 水平方向 */
  align-items: center;   /* 垂直方向 */
}
```

> `stretch` 的效果：子元素未给大小时，默认会被拉伸填满整个单元格。

### 响应式布局

```css
.box {
  display: grid;
  /* 自动填充，设置了最小值为 210px，最大为 1 份 */
  grid-template-columns: repeat(auto-fill, minmax(210px, 1fr));
  max-width: 1350px;
  margin: 30px auto;
  gap: 18px;
}
```

> 容器变宽时自动增加列数，容器变窄时自动减少列数，无需媒体查询即可实现基础响应式。

.box {

## 定位布局

CSS 定位布局（position）是控制元素在页面中位置的核心技术之一。通过定位，可以实现元素脱离文档流、层叠、固定在特定位置等布局效果（定位跟位置有关）。

**场景：**

1. 固定导航栏。页面滚动时导航栏始终固定在视口顶部。
2. 吸顶效果。元素在滚动到某个位置后固定。
3. 弹出菜单/下拉框。鼠标悬停时显示浮动菜单。
4. 悬浮效果。元素悬浮在其他元素上方。

**定位分类：**相对定位　　绝对定位　　固定定位　　粘性定位

### 相对定位

CSS 相对定位（`position: relative`）是布局中常用的定位方式，其核心在于元素相对于自身正常位置进行偏移。

**场景：**和绝对定位搭配使用。主要作用是「给绝对定位当爹」。

**语法：**`position: relative;` 设定元素为相对定位

- 相对于自身原来位置移动距离。
- 不脱离正常流，元素原位置仍被保留，其他元素按原布局排列。
- 可以通过 `top`、`bottom`、`left`、`right` 属性进行偏移。
- 优先级：若同时设置 `top` 和 `bottom`，仅 `top` 生效；同理 `left` 覆盖 `right`。

```css
.box {
  width: 200px;
  height: 200px;
  background-color: pink;
  /* 给元素添加相对定位 */
  position: relative;
  top: 100px;
  left: 100px;
}
```

### 绝对定位

CSS 绝对定位（`position: absolute`）核心是脱离正常流并基于定位基准进行偏移。

**场景：**

1. 弹出菜单/下拉框。鼠标悬停时显示浮动菜单。
2. 悬浮效果。元素悬浮在其他元素上方。

**语法：**`position: absolute;` 设定元素为绝对定位

- 元素脱离正常流，不占据空间，其他元素按原布局排列。
- 相对于最近的已定位祖先元素（position 非 static）移动位置。若都无定位则相对于视口来定位。
- 可以通过 `top`、`bottom`、`left`、`right` 属性进行偏移。
- 优先级：若同时设置 `top` 和 `bottom`，仅 `top` 生效；同理 `left` 覆盖 `right`。

```css
.father {
  position: relative;  /* 父盒子作为定位基准 */
  width: 400px;
  height: 400px;
  background-color: pink;
}
.son1 {
  position: absolute;
  right: 20px;
  bottom: 50px;
  width: 150px;
  height: 150px;
  background-color: skyblue;
}
```

### 子绝父相

定位最常用的布局技巧：**子绝父相**（子元素绝对定位、父元素相对定位）。

**为什么是子绝父相？**

1. 子元素可以悬浮在其他元素上方，就不能占有位置、影响其他元素布局，所以用**绝对定位**。
2. 但是子元素不能随便乱跑，要配合父元素移动位置，此时父元素需要加**定位**。
3. 父元素需要占原来的位置，不能影响其他元素布局，此时**相对定位**最合适。

> 小兔鲜首页中，搜索框图标、购物车角标、轮播图左右箭头与底部指示点，都是「子绝父相」的典型应用。

**小技巧一：用阴影代替边框，避免盒子变大**

如果用边框实现高亮描边，会比较麻烦：

1. 边框会增大盒子尺寸，需要把盒子模型改为 `box-sizing: border-box;`（这样边框才计入宽度、不撑大盒子）
2. 若仍用默认的 `content-box`，盒子变大，会影响后面小圆点的排列。

用阴影更简单——阴影不占位置，不会增加盒子大小，从而不影响布局：

```css
/* 鼠标经过利用阴影实现边框效果 */
.banner .circle li:hover {
  box-shadow: 0 0 0 4px rgba(255, 255, 255, 0.5);
  background-color: #fff;
}
```

**小技巧二：定位的盒子垂直居中**

绝对定位的盒子无法用 `margin: 0 auto;` 居中，需要「先走一半，再拉回自身的一半」：

```css
.box {
  position: absolute;
  top: 50%;             /* 1. 盒子顶边走到父盒子中线 */
  margin-top: -60px;    /* 2. 往上走盒子自身高度的一半（假设高 120px） */
  left: 50%;            /* 水平方向同理 */
  margin-left: -300px;  /* 假设宽 600px */
  width: 600px;
  height: 120px;
  background-color: rgba(0, 0, 0, 0.5);
  border-radius: 15px;
}
```

**综合案例：好玩的猫咪效果（定位 + 伪元素遮罩 + 横向滚动）**

```css
.box {
  overflow: hidden;
  position: relative;   /* 父盒子相对定位 */
  width: 1000px;
  margin: 100px auto;
}
/* 用伪元素做上下两个弧形遮罩，遮住图片边缘形成环形效果 */
.box::before,
.box::after {
  position: absolute;
  left: 0;
  content: '';
  width: 100%;
  height: 100px;
  background-color: #fff;   /* 背景色与网页底色一致 */
  border-radius: 50%;
  text-align: center;
  color: #000;
}
.box::before {
  top: -50px;
  content: '可爱的小猫咪，滚动鼠标滚轮可以查看哦~~~';
  line-height: 120px;
}
.box::after {
  bottom: -50px;
  content: '你喜欢我们吗？ 点击可以查看哦！';
  line-height: 60px;
}
.box ul {
  display: flex;
  gap: 15px;
  overflow-x: auto;           /* 可以横向滚动（关键：否则 scrollLeft 不生效） */
  scrollbar-width: none;      /* 隐藏滚动条 */
  scroll-behavior: smooth;    /* 平滑滚动 */
}
.box ul::-webkit-scrollbar {
  display: none;              /* 隐藏 WebKit 浏览器滚动条 */
}
.box ul li {
  flex: 0 0 200px;            /* 不拉伸、不收缩，初始宽度 200px */
}
.box ul li img {
  width: 100%;
}
```

配合 JS 把纵向滚轮转为横向滚动：

```js
const scrollContainer = document.querySelector('.box ul');
scrollContainer.addEventListener('wheel', (e) => {
  e.preventDefault();                            // 阻止默认的垂直滚动
  scrollContainer.scrollLeft += e.deltaY * 1.5;  // 纵向滚动量转为横向滚动量
});
```

> **原理：**利用 `::before` 和 `::after` 盖住图片上下边缘，背景色与网页底色一致，从而形成弧形遮罩。

### 固定定位

CSS 固定定位（`position: fixed`）是一种将元素脱离文档流并始终相对于浏览器视口定位的布局技术。

**场景：**

1. 固定导航栏。页面滚动时导航栏始终固定在视口顶部。
2. 页面广告。广告覆盖整个页面。

**语法：**`position: fixed;` 设定元素为固定定位

- 元素脱离正常流，不占据空间，其他元素按原布局排列。
- 始终相对于浏览器窗口（视口）定位，滚动页面时位置不变。
- 可以通过 `top`、`bottom`、`left`、`right` 属性进行偏移。
- 优先级：若同时设置 `top` 和 `bottom`，仅 `top` 生效；同理 `left` 覆盖 `right`。

```css
.box {
  position: fixed;
  left: 50%;            /* 水平居中：先走一半 */
  margin-left: -300px;  /* 再拉回自身宽度的一半 */
  bottom: 30px;
  width: 600px;
  height: 120px;
  background-color: rgba(0, 0, 0, 0.5);
  border-radius: 15px;
  /* margin: 0 auto; 对于定位的盒子无效 */
}
```

### 粘性定位

CSS 粘性定位（`position: sticky`）是一种**混合定位模式**，结合了相对定位（relative）和固定定位（fixed）的特性。

**场景：**

1. 吸顶效果。元素在滚动到某个位置后固定。
2. 表格表头固定。长表格滚动时表头始终可见。

**语法：**`position: sticky;` 设定元素为粘性定位

- 元素在滚动到指定位置（如 `top: 10px`）前为相对定位，之后转为固定定位。
- 吸顶的参照物取决于**最近的滚动容器**：若祖先元素都没有滚动（`overflow: visible`），则相对视口吸顶；若某个祖先设置了 `overflow: auto/hidden` 等并成为滚动容器，则相对该容器吸顶。想让吸顶相对视口生效，祖先的 `overflow` 就需要是 `visible`。
- 可以通过 `top`、`bottom`、`left`、`right` 属性进行偏移。
- **必须**指定 `top`、`right`、`bottom` 或 `left` 四个其中之一，才可使粘性定位生效。

```css
.nav {
  position: sticky;
  top: 0;
  width: 1000px;
  height: 100px;
  background-color: pink;
  margin: 100px auto;
}
.main {
  height: 2000px;
  background-color: skyblue;
}
```

**典型应用：表格表头吸顶**

```css
.table {
  height: calc(100% - 60px);
  overflow-y: auto;      /* 滚动容器 */
}
.table-header {
  position: sticky;
  top: 0;                /* 表头滚动到顶部时固定 */
  display: flex;
  background-color: #f8f9fa;
}
```

### z-index 叠放次序

**z-index** 属性用于控制元素在**三维空间中的层叠顺序**（即 Z 轴方向）。当多个元素在同一平面（如同一行或列）重叠时，**z-index** 决定哪个元素显示在最上层。

> **场景：**
>
> 1. 提高层级悬浮效果。
> 2. 实现图片层叠效果。
>
> **语法：**`z-index: 数值;` 设定层级
>
> - 值类型：整数（正数、负数、零）或 `auto`。数值越大，层级越高
> - 默认值：`auto`（等同于未设置，后出现的元素覆盖前者）
> - 生效条件：仅对**定位元素**（position 值为 relative、absolute、fixed 或 sticky）有效

```css
.box img {
  position: absolute;
}
.box img:hover {
  z-index: 1;   /* 鼠标经过时提升层级，显示在最上层 */
}
```

### 定位总结

| 定位类型 | 脱离文档流 | 定位基准            | 层叠控制 | 典型场景                 |
| :------- | :--------: | :------------------ | :------: | :----------------------- |
| static   |     否     | 默认文档流          |    无    | 普通元素布局             |
| relative |     否     | 自身正常位置        |   支持   | 微调元素、子绝父相       |
| absolute |     是     | 最近定位祖先 / 视口 |   支持   | 弹窗、下拉菜单、悬浮元素 |
| fixed    |     是     | 视口                |   支持   | 固定导航栏、返回顶部按钮 |
| sticky   |     否     | 视口或滚动祖先      |   支持   | 吸顶导航栏、侧边栏固定   |

> **定位三要素：**
>
> - `position`（static / relative / absolute / fixed / sticky）
> - 偏移属性 `top` / `right` / `bottom` / `left` 控制元素偏移量
> - `z-index` 控制层叠顺序，数值越大层级越高

> **常见组合：**
>
> - 固定导航栏：`position: fixed + z-index`
> - 弹窗：`position: fixed + 居中技巧 + 高 z-index`
> - 吸顶效果：`position: sticky + top`

## 多列布局

多列布局用于将元素的内容**自动分割**为指定数量的垂直列。

**场景：**

1. 长文章分栏。文章自动分列，中间有间隙，也可以做响应式。
2. 图片瀑布流。

> **与 flex / grid 瀑布流的区别：**flex 或 grid 需要手动把内容分组到每一列；多列布局（column）则由浏览器**自动**按列从上到下填充，内容会优先填满一列后再流入下一列。

| 属性         | 作用                                         | 示例值                        |
| :----------- | :------------------------------------------- | :---------------------------- |
| column-count | 根据容器宽度和 column-count 值，自动分配列宽 | `column-count: 3;` 分为 3 列  |
| column-gap   | 列之间的间距                                 | `20px`、`normal`（默认 1em）  |
| column-rule  | 列间的分隔线样式（颜色、宽度、样式）         | `column-rule: 1px solid #ccc` |

```css
.box {
  column-count: 5;
  column-gap: 20px;
  column-rule: 1px dashed red;
  max-width: 1200px;
}
```

**注意：底部子元素被“切断”**

原因：`column-count` 的本质是将内容按垂直方向自动分割到多列（类似报纸排版），内容会优先填满一列后再流入下一列，因此单个盒子可能被拆到两列中。

**解决方案：**给子元素添加 `break-inside: avoid-column;`，强制元素不跨列分割（默认 `auto`，允许跨列）。

```css
.box .item {
  height: 150px;
  background-color: pink;
  margin-bottom: 20px;
  /* 不允许盒子被切割 */
  break-inside: avoid-column;
  -webkit-column-break-inside: avoid;
}
```

## 鼠标样式

在 CSS 中，`cursor` 属性用于控制鼠标指针在元素上的显示样式，通过改变光标形态可以向用户传递交互提示（如“可点击”“不可选中”等），从而提升界面交互体验。

| 值            | 描述                                                                                         |
| :------------ | :------------------------------------------------------------------------------------------- |
| `default`     | 默认箭头（通常是系统默认的箭头光标）                                                         |
| `pointer`     | 手型（指尖朝下的小手），常用于**可点击元素**（如链接 `<a>`、按钮 `<button>`）                 |
| `text`        | I 型竖线（类似文本输入光标），用于**可编辑文本区域**（如 `<textarea>`、contenteditable 元素） |
| `wait`        | 等待（旋转圆圈或沙漏），表示**操作进行中**（如加载、提交时）                                 |
| `help`        | 帮助（带问号的箭头），提示用户**需要帮助**（如提示信息区域）                                 |
| `not-allowed` | 禁止（圆圈带斜线），表示**操作不可用**（如禁用的按钮）                                       |
| `grab`        | 抓取（手型带抓取动作），表示**可拖动**（如可拖拽的元素）                                     |
| `grabbing`    | 抓取中（手型收紧），表示**正在拖动**（配合 `grab` 使用）                                     |
| `zoom-in`     | 放大（+ 号），表示**放大操作**（如图片预览时）                                               |
| `zoom-out`    | 缩小（- 号），表示**缩小操作**（如图片预览时）                                               |

```html
<li style="cursor: pointer;">鼠标样式 pointer</li>
<li style="cursor: not-allowed;">鼠标样式 not-allowed</li>
```

## CSS书写顺序

合理的属性顺序应遵循「**布局 → 盒模型 → 视觉 → 交互 → 其他**」的逻辑，核心目标是让代码更易读、易维护。
实际开发中可根据项目需求微调，但保持团队一致性是关键！

| 顺序              | 常见属性列表                                                                                                                                                                                                                                       |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 布局相关          | `display`（显示类型）、`visibility`（可见性）、`position`（定位方式）、`top/right/bottom/left`（定位偏移）、`float`（浮动）、`clear`（清除浮动）、`overflow`（溢出处理）、`z-index`（层叠顺序）、`clip`（裁剪）                                      |
| 盒模型            | `box-sizing`（盒模型计算方式）、`width/min-width/max-width`（宽度）、`height/min-height/max-height`（高度）、`margin`（外边距）、`padding`（内边距）、`border`（边框）、`outline`（轮廓，可选）                                                     |
| 视觉样式          | `color`（文本颜色）、`background`（背景，含 `background-color`/`background-image` 等）、`font`（字体合写）、`font-size`（字号）、`font-family`（字体系列）、`line-height`（行高）、`text-align`（文本对齐）、`text-indent`（首行缩进）、`letter-spacing`（字间距）、`white-space`（空白处理） |
| 交互与动画        | `cursor`（鼠标指针）、`opacity`（透明度）、`transition`（过渡）、`animation`（动画）、`transform`（变换，如旋转、缩放）                                                                                                                              |
| 其他（特殊/低频） | `filter`（滤镜）、`clip-path`（裁剪路径）、`backdrop-filter`（背景滤镜）、`will-change`（优化提示）、`touch-action`（触摸行为）、`scroll-behavior`（滚动行为）                                                                                        |
