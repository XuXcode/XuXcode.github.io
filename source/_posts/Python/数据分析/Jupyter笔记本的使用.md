# Jupyter笔记本的使用

## Jupyter快捷键

| 快捷键      | 功能                            |
| ----------- | ------------------------------- |
| esc         | 从输入模式退出到命令模式        |
| a           | 在当前cell上面创建一个新的cell  |
| b           | 在当前cell 下面创建一个新的cell |
| dd          | 删除当前cell                    |
| m           | 切换到markdown模式              |
| y           | 切换到code模式                  |
| ctrl+回车   | 运行cell                        |
| shift +回车 | 运行当前cell并创建一个新的cell  |
