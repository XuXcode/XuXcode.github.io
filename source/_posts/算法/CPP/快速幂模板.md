# 快速幂模板



### 求a^b的值

```cpp
using ll=long long;
qpow(ll a,ll b){
    while(b){
        ll ans=1;
        if(b&1) ans*=a;
        a=a*a;
        b>>=1;
    }
    return ans;
}
```
