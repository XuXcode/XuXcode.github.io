我是 **XuX**，软件工程专业本科生，主要在做 Java 后端开发与 AI 应用方向的实践。

这个博客用来记录我在技术上的探索过程：读源码时的理解、写项目时踩过的坑，以及一些能沉淀下来的总结。我更愿意把它当成一份可检索的学习档案，而不是作品集式的展示。

## 技术方向

**Java 后端**

Spring Boot、Spring MVC、MyBatis、MySQL、Redis，目前的学习重点在后端业务分层设计、接口开发与常见中间件的实际使用。

**AI Agent 与大模型应用**

Python、FastAPI、LLM API 调用、Tool Calling、Agent Loop、RAG 检索增强。这一方向还在持续学习中，实践多于完整的方法论沉淀。

**工程与工具**

Git、GitHub、Maven、Linux 基础操作，以及 Vue3 的前端基础能力，能配合完成后端接口到页面展示的完整链路。

> 上面列的是我正在使用的技术，不代表都达到精通程度。深入学习过和只是用过的东西，我在文章里会尽量分清。

## 关于写作

大部分文章的起点都是「这个东西我当时没看懂」。比如为了搞清楚 Spring AOP 为什么能让一个注解生效，我写下了[《Spring AOP 原理剖析》](https://xuxcode.github.io/2026/11/07/Java/Javaweb/Spring%20AOP%20%E5%8E%9F%E7%90%86%E5%89%96%E6%9E%90%EF%BC%9A%E4%B8%BA%E4%BB%80%E4%B9%88%E4%B8%80%E4%B8%AA%E6%B3%A8%E8%A7%A3%E5%B0%B1%E8%83%BD%E5%AE%9E%E7%8E%B0%E5%85%AC%E5%85%B1%E5%AD%97%E6%AE%B5%E8%87%AA%E5%8A%A8%E5%A1%AB%E5%85%85%EF%BC%9F) 那篇；项目里的问题会被我整理成项目日记的形式。

我会尽量做到：

- 写清楚「为什么」而不只是「怎么用」
- 代码和结论都经过自己实际验证
- 不确定的地方直接说明，不硬凑
