## 工业机器人多模态智能检修系统

**项目定位**　面向工业机器人检修场景的智能辅助系统，把设备时序数据、异常事件、知识库与检修流程串起来，辅助工程师完成诊断和检修决策。

**技术栈**　Java · Spring Boot · Python · FastAPI · Vue3 · MySQL · Redis · RAG · AI Agent

**核心功能**

- 设备时序数据监测与异常事件管理
- 基于知识库检索的智能诊断
- 标准作业程序（SOP）生成
- 检修工单闭环流转

**个人负责部分**　后端服务设计与实现，包括业务接口分层、异常事件相关模块、以及 Python AI 服务与 Java 后端的对接。

**项目状态**　开发中

## 湖南省充电设施可视化与选址优化系统

**项目定位**　面向区域充电设施规划的数据分析系统，通过空间分布与可达性分析，识别设施覆盖薄弱区域，为布局优化提供依据。

**技术栈**　Vue3 · ECharts · FastAPI · MySQL · 地理空间分析

**核心功能**

- 充电设施空间分布分析
- 可达性分析
- 供需协调分析
- 薄弱区域识别与布局优化建议

**个人负责部分**　数据可视化模块与部分后端分析接口的开发。

**项目状态**　开发中

## 苍穹外卖项目实践

**项目定位**　后端业务开发的完整练习项目，覆盖从环境搭建、接口开发到中间件使用的完整链路，是我系统实践 Spring Boot 业务开发的主要载体。

**技术栈**　Java · Spring Boot · MyBatis · Redis · MySQL

**核心功能**

- 员工、分类、菜品、套餐等业务模块的接口开发
- 基于 JWT 的登录校验与拦截器
- 公共字段自动填充（AOP + 自定义注解 + 反射）
- 缓存与接口优化

**个人负责部分**　独立完成后端全部模块的编码与调试。

**项目状态**　已完成
